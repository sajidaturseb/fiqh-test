# Фикһ тестлары

Интерактивный учебный тест на татарском языке по двухлетней программе фикха на основе ханафитского мазхаба.

- 50 уроков
- 560 вопросов
- промежуточный тест на 30 вопросов
- итоговый зачет на 50 вопросов
- проверка результата и разбор ошибок

Сайт работает в браузере. В назначенных преподавателем тестах имя, группа и результат ученика отправляются в приватный журнал Supabase.

## Supabase

Результаты хранятся в приватной таблице `quiz_attempts`. Браузер не имеет прямого доступа к таблице: запись и чтение выполняет Edge Function `submit-quiz`. Чтение результатов требует секрет `TEACHER_PIN`.

Основные команды выполняются из корня проекта:

```text
pnpm dlx supabase@2.117.0 db push --linked
pnpm dlx supabase@2.117.0 functions deploy submit-quiz --no-verify-jwt --use-api
pnpm dlx supabase@2.117.0 secrets set TEACHER_PIN=<новый PIN>
```

Панель преподавателя публикуется как `dist/teacher.html`.
