# Фикһ тестлары

Интерактивный учебный тест на татарском языке по двухлетней программе фикха на основе ханафитского мазхаба.

- 50 уроков
- 560 вопросов
- промежуточный тест на 30 вопросов
- итоговый зачет на 50 вопросов
- проверка результата и разбор ошибок

Сайт работает полностью в браузере и не собирает персональные данные.
